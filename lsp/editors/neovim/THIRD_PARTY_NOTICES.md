# Third-Party Notices

This Clyth Neovim integration bundles only Clyth-authored integration files, Clyth syntax support, and prebuilt `clyth-lsp` binaries.

It uses Neovim's built-in LSP client and does not bundle third-party Neovim plugins or libraries. Neovim itself is an external editor host and is not redistributed with this package.
