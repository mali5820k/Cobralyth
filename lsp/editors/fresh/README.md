# Fresh

Fresh supports installable language packs containing syntax highlighting, language configuration, and LSP startup metadata.

With `clyth-lsp` on `PATH`, install this directory as a local language pack from Fresh's package UI (Package: Install from URL, using the absolute path to this directory), or copy it into Fresh's local grammar/package configuration area. Opening a `.clyth` file will then auto-start `clyth-lsp`.
